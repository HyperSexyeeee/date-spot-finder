# Date Spot Finder

掛川・静岡のデートスポットをランダムで提案するシンプル Web アプリ。

## デモ

（公開 URL をここに貼る予定）
`https://<ユーザー名>.github.io/date-spot-finder/`

## 使い方

- 「表示する！」：入力したテキストを表示
- 「おすすめスポット」：JSON（spots.json）からランダムに 1 件表示

## 主要ファイル

- `index.html` … 画面の骨組み
- `css/style.css` … デザイン
- `script.js` … 動作（イベント処理・JSON 読み込み）
- `spots.json` … スポットデータ

## 技術スタック

HTML / CSS / JavaScript / fetch(JSON) / GitHub Pages

## 開発メモ

- Live Server で動作確認（`http://127.0.0.1:5500/`）
- 反映が遅い時は `Ctrl+F5` または `?v=2` を URL 末尾に付ける
